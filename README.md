## ✨ Возможности

### 🚶 Навигация по тактильной дорожке
- **Распознавание тактильной дорожки в реальном времени**: сегментационная модель YOLO
- **Голосовые подсказки**: точные указания направления (налево, направо, прямо и т. д.)
- **Обнаружение и обход препятствий**: автоматически находит препятствия впереди и строит маршрут обхода
- **Обнаружение поворотов**: распознаёт крутые повороты и заранее предупреждает
- **Стабилизация оптическим потоком**: алгоритм Lucas-Kanade стабилизирует маску и уменьшает дрожание

### 🚦 Помощь при переходе улицы
- **Распознавание зебры**: положение и направление пешеходного перехода в реальном времени
- **Распознавание светофора**: определение сигнала по цвету и форме
- **Выравнивание**: подводит пользователя к центру зебры
- **Предупреждения**: на зелёный голосом сообщает, что можно идти

### 🔍 Распознавание и поиск предметов
- **Поиск по голосу**: поиск предмета голосовой командой (например, «помоги найти Red Bull»)
- **Отслеживание в реальном времени**: детекция YOLO-E с открытым словарём + трекинг ByteTrack
- **Наведение руки**: с помощью детекции рук MediaPipe подводит руку пользователя к предмету
- **Определение захвата**: распознаёт хват и подтверждает, что предмет взят
- **Мультимодальная обратная связь**: разметка на видео + голосовые подсказки + подсказки центрирования

### 🎙️ Голосовое общение в реальном времени
- **Распознавание речи (ASR)**: потоковое распознавание Alibaba Cloud DashScope Paraformer
- **Мультимодальный диалог**: Qwen-Omni-Turbo принимает изображение + текст и отвечает голосом
- **Разбор команд**: автоматически отличает команды навигации, поиска и обычный разговор
- **Учёт контекста**: в разных режимах отфильтровывает неуместные команды

### 📹 Обработка видео и звука
- **Видеопоток в реальном времени**: трансляция по WebSocket, одновременно несколько зрителей
- **Синхронная запись видео и звука**: автоматически сохраняет видео и аудио с отметками времени
- **Данные IMU**: принимает IMU с ESP32, поддерживает оценку ориентации
- **Многоканальное микширование**: одновременно системные подсказки, ответы ИИ и окружающий звук

### 🎨 Визуализация и интерфейс
- **Веб-мониторинг**: обработанный видеопоток в браузере в реальном времени
- **3D-визуализация IMU**: ориентация устройства через Three.js
- **Панель состояния**: режим навигации, результаты детекции, FPS и т. д.
- **Китайский язык**: весь интерфейс и озвучка на китайском, можно подключить свои шрифты

## 💻 Системные требования

### Оборудование
- **Разработка / сервер**:
  - CPU: Intel i5 или выше (рекомендуется i7/i9)
  - GPU: NVIDIA с поддержкой CUDA 11.8+ (рекомендуется RTX 3060 или выше)
  - ОЗУ: 8 ГБ (рекомендуется 16 ГБ)
  - Диск: 10 ГБ свободного места

- **Клиентское устройство** (необязательно):
  - ESP32-CAM или другая камера с поддержкой WebSocket
  - Микрофон (голосовой ввод)
  - Динамик / наушники (голосовой вывод)

### Программное обеспечение
- **ОС**: Windows 10/11, Linux (Ubuntu 20.04+), macOS 10.15+
- **Python**: 3.9–3.11
- **CUDA**: 11.8 или новее (обязательно для ускорения на GPU)
- **Браузер**: Chrome 90+, Firefox 88+, Edge 90+ (для веб-мониторинга)

### API-ключи
- **Ключ Alibaba Cloud DashScope API** (обязателен):
  - Для распознавания речи (ASR) и диалога Qwen-Omni
  - Получить: https://dashscope.console.aliyun.com/

## 🚀 Быстрый старт

### 1. Клонировать проект

```bash
git clone https://github.com/yourusername/aiglass.git
cd aiglass/rebuild1002
```

### 2. Установить зависимости

#### Создать виртуальное окружение (рекомендуется)
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate
```

#### Установить пакеты Python
```bash
pip install -r requirements.txt
```

#### Установить CUDA и cuDNN (ускорение на GPU)
См. [руководство по установке NVIDIA CUDA Toolkit](https://developer.nvidia.com/cuda-downloads)

### 3. Скачать модели

Положите следующие файлы в каталог `model/`:

| Файл модели | Назначение | Размер | Ссылка |
|---------|------|------|---------|
| `yolo-seg.pt` | Сегментация тактильной дорожки | ~50 МБ | [будет добавлено] |
| `yoloe-11l-seg.pt` | Детекция с открытым словарём | ~80 МБ | [будет добавлено] |
| `shoppingbest5.pt` | Распознавание предметов | ~30 МБ | [будет добавлено] |
| `trafficlight.pt` | Детекция светофора | ~20 МБ | [будет добавлено] |
| `hand_landmarker.task` | Детекция рук | ~15 МБ | [MediaPipe Models](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker#models) |

### 4. Настроить API-ключ

Создайте файл `.env`:

```bash
# .env
DASHSCOPE_API_KEY=your_api_key_here
```

Или поменяйте прямо в коде (не рекомендуется):
```python
# app_main.py, line 50
API_KEY = "your_api_key_here"
```

### 5. Запустить систему

```bash
python app_main.py
```

Система запустится на `http://0.0.0.0:8081`; откройте адрес в браузере, чтобы увидеть интерфейс мониторинга.

### 6. Подключить устройство (необязательно)

Если используете ESP32-CAM:
1. Прошейте `compile/compile.ino` в ESP32
2. Измените настройки Wi-Fi, чтобы устройство было в той же сети
3. ESP32 автоматически подключится к WebSocket-эндпоинту

## 📖 Использование

### Голосовые команды

Система понимает следующие голосовые команды (слово активации не нужно). Команды произносятся по-китайски; в скобках — перевод:

#### Управление навигацией
```
"开始导航" / "盲道导航"     (начать навигацию / навигация по дорожке) → запуск навигации по тактильной дорожке
"停止导航" / "结束导航"     (остановить / завершить навигацию)        → остановка навигации
"开始过马路" / "帮我过马路"  (начать переход / помоги перейти улицу)    → режим перехода улицы
"过马路结束" / "结束过马路"  (переход окончен / завершить переход)      → выход из режима перехода
```

#### Детекция светофора
```
"检测红绿灯" / "看红绿灯"   (распознать светофор / посмотри на светофор) → запуск детекции светофора
"停止检测" / "停止红绿灯"   (остановить детекцию / стоп светофор)       → остановка детекции
```

#### Поиск предметов
```
"帮我找一下 [предмет]"       (помоги найти [предмет]) → запуск поиска предмета
  Примеры:
  - "帮我找一下红牛"   (помоги найти Red Bull)
  - "找一下AD钙奶"     (найди AD Calcium Milk — молочный напиток)
  - "帮我找矿泉水"     (помоги найти минеральную воду)
"找到了" / "拿到了"   (нашёл / взял) → подтверждение, что предмет найден
```

#### Свободный диалог
```
"帮我看看这是什么"   (посмотри, что это) → распознавание по снимку
"这个东西能吃吗"     (это можно есть?)   → вопрос о предмете
Любой другой вопрос                       → диалог с ИИ
```

### Состояния навигации

Основные состояния системы (переключаются автоматически):

1. **IDLE** — ожидание
   - Ждёт команду пользователя
   - Показывает исходный видеопоток

2. **CHAT** — режим диалога
   - Мультимодальный диалог с ИИ
   - Навигация приостановлена

3. **BLINDPATH_NAV** — навигация по тактильной дорожке
   - **ONBOARDING**: выход на дорожку
     - ROTATION: поворот, чтобы встать по направлению дорожки
     - TRANSLATION: смещение к центру дорожки
   - **NAVIGATING**: движение по дорожке
     - Коррекция направления в реальном времени
     - Детекция препятствий
   - **MANEUVERING_TURN**: прохождение поворота
   - **AVOIDING_OBSTACLE**: обход препятствия

4. **CROSSING** — режим перехода улицы
   - **SEEKING_CROSSWALK**: поиск зебры
   - **WAIT_TRAFFIC_LIGHT**: ожидание зелёного
   - **CROSSING**: переход
   - **SEEKING_NEXT_BLINDPATH**: поиск тактильной дорожки на другой стороне

5. **ITEM_SEARCH** — поиск предмета
   - Детекция нужного предмета в реальном времени
   - Наведение руки
   - Подтверждение захвата

6. **TRAFFIC_LIGHT_DETECTION** — детекция светофора
   - Определение сигнала в реальном времени
   - Голосом сообщает о смене цвета

### Веб-интерфейс мониторинга

Откройте в браузере `http://localhost:8081`, там видно:

- **Видеопоток**: обработанное видео с навигационной разметкой
- **Панель состояния**: текущий режим, результаты детекции, FPS
- **Визуализация IMU**: 3D-ориентация устройства в реальном времени
- **Результаты распознавания речи**: распознанный текст и ответы ИИ

### WebSocket-эндпоинты

| `/ws_audio` | Загрузка звука с ESP32 | Binary (PCM16) |
| `/ws_ui` | Отправка состояния в UI | JSON |

| `/stream.wav` | Поток звука для скачивания | Binary (WAV) |

## ⚙️ Настройка

### Переменные окружения

Создайте файл `.env` со следующими параметрами:

```bash
# Alibaba Cloud API
DASHSCOPE_API_KEY=sk-xxxxx

# Пути к моделям (необязательно; при путях по умолчанию можно не задавать)
BLIND_PATH_MODEL=model/yolo-seg.pt
OBSTACLE_MODEL=model/yoloe-11l-seg.pt
YOLOE_MODEL_PATH=model/yoloe-11l-seg.pt

# Параметры навигации
AIGLASS_MASK_MIN_AREA=1500      # Минимальная площадь маски
AIGLASS_MASK_MORPH=3            # Размер ядра морфологии
AIGLASS_MASK_MISS_TTL=6         # Сколько кадров допускается потеря маски
AIGLASS_PANEL_SCALE=0.65        # Масштаб панели данных

# Звук
TTS_INTERVAL_SEC=1.0            # Интервал между голосовыми сообщениями
ENABLE_TTS=true                 # Включить озвучку
```

### Изменение путей к моделям

Если модели лежат не на месте по умолчанию, поменяйте пути в соответствующих файлах:

```python
# workflow_blindpath.py
seg_model_path = "your/custom/path/yolo-seg.pt"

# yolomedia.py
YOLO_MODEL_PATH = "your/custom/path/shoppingbest5.pt"
HAND_TASK_PATH = "your/custom/path/hand_landmarker.task"
```

### Параметры производительности

Подстройте под своё оборудование:

```python
# yolomedia.py
HAND_DOWNSCALE = 0.8    # Уменьшение кадра для детекции рук (меньше — быстрее, но ниже точность)
HAND_FPS_DIV = 1        # Прореживание кадров для детекции рук (2 = через кадр, 3 = каждый 3-й)

# workflow_blindpath.py  
FEATURE_PARAMS = dict(
    maxCorners=600,      # Число точек для оптического потока (меньше — быстрее)
    qualityLevel=0.001,  # Порог качества точек
    minDistance=5        # Минимальное расстояние между точками
)
```

### Добавление голосовой команды
