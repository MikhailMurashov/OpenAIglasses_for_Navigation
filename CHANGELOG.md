# Журнал изменений

## [1.0.0] - 2025-01-XX

### Добавлено
- 🚶 Навигация по тактильной дорожке
  - Детекция и сегментация дорожки в реальном времени
  - Голосовые подсказки
  - Детекция и обход препятствий
  - Распознавание крутых поворотов и предупреждения о них
  - Стабилизация оптическим потоком

- 🚦 Помощь при переходе улицы
  - Распознавание зебры и её направления
  - Распознавание цвета светофора
  - Подсказки для выравнивания
  - Предупреждения о безопасности

- 🔍 Распознавание и поиск предметов
  - Детекция YOLO-E с открытым словарём
  - Наведение руки с помощью MediaPipe
  - Отслеживание цели в реальном времени
  - Распознавание захвата

- 🎙️ Голосовое общение в реальном времени
  - Alibaba Cloud Paraformer ASR
  - Мультимодальный диалог Qwen-Omni-Turbo
  - Разбор команд
  - Учёт контекста

- 📹 Обработка видео и звука
  - Трансляция по WebSocket в реальном времени
  - Синхронная запись видео и звука
  - Объединение с данными IMU
  - Многоканальное микширование звука

- 🎨 Визуализация и интерфейс
  - Веб-интерфейс мониторинга в реальном времени
  - 3D-визуализация IMU
  - Панель состояния
  - Интерфейс на китайском

### Технологии
- FastAPI + WebSocket
- YOLO11 / YOLO-E
- MediaPipe
- PyTorch + CUDA
- OpenCV
- DashScope API

### Известные проблемы
- [ ] Возможны подтормаживания на слабых GPU
- [ ] На macOS нет ускорения на GPU
- [ ] Часть китайских шрифтов неправильно отображается в Linux
